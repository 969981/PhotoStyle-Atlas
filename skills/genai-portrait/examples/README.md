# Synthetic Example

Every person shown in this directory is synthetic and was generated specifically for this open-source demonstration.

## Artifacts

- `assets/synthetic_white_input.png`: synthetic white-background source portrait.
- `assets/synthetic_gemini_lighting_reference.png`: lighting concept candidate.
- `assets/synthetic_dark_final.png`: identity-authoritative GPT lighting transfer.
- `assets/synthetic_workflow_comparison.jpg`: side-by-side review sheet.
- `prompts/gemini_lighting_reference.txt`: lighting-reference prompt.
- `prompts/gpt_identity_transfer.txt`: two-image transfer prompt.

These committed images document one successful model combination, not a required pipeline. The canonical skill instructs the agent to inspect results and adapt.
