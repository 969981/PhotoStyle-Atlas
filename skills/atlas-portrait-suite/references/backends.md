# 实际执行后端选择

| 需求 | 推荐后端 | 说明 |
| --- | --- | --- |
| RAW 基础曝光、HSL、批量统一调色 | Lightroom/Camera Raw 或已连接相应 MCP | 非生成式，容易保留几何，导出仍要做色彩管理 |
| 蒙版、频率分离、局部补光、PSD | Photoshop 与已连接 Photoshop MCP | 图层可编辑，优先备份原图 |
| 需要改变光源、换场景、扩图 | 可用的原图编辑生成模型 / GenAI Portrait | 只能在授权下生成，须做身份复核 |
| 去路人/局部商业精修 | Roby Photo Retouch Pro + 真正图像编辑工具 | Skill 是方法论，不是编辑器 |
| 视频逐帧场景特效 | AInVFX Paint a Plate（外部索引） | ComfyUI 视频工具，显存需求高，不是静态照片默认方案 |

**工具检查**：没有可执行后端时只输出步骤与参数，不能把建议当成已完成图像。不得把用户的私人人像、API Key、完整 PSD 自动提交到公开仓库。云端 API 需要额外考虑照片上传与费用。
