# 身份与画质 QA

**身份参考 = 原图**。不同图片角色需明确：第二张可用于光线/背景参考，但不得用于五官迁移。默认保护脸宽、眼角/瞳孔、鼻口、下颌、耳、发际线、标志痣疤、胡须、年龄线索、姿势、比例、衣服图案、眼镜和文字。

| 校验 | 应观察什么 | 不合格处理 |
| --- | --- | --- |
| 五官 | 轮廓、眉眼鼻唇、自然不对称与原图相同 | 回到源图重试，缩小解锁范围 |
| 皮肤 | 肤色宽频平滑但保留细节，无蜡皮/假毛孔/脏 HDR | 降低磨皮与锐化；重新处理肤色区 |
| 光线 | 亮面、影面、眼神光与衣服都能解释 | 更正光源方向/补光强度 |
| 合成 | 发丝透明边缘、地面接触影、景深/透视一致 | 重新处理蒙版、边缘与投影 |
| 导出 | 原件未覆盖，颜色空间与像素尺寸可验证 | 另存并如实报告处理情况 |

多轮编辑：保留 `root-base`、`last-approved`、`current-target`、`look-reference`。当画质退化时从最近合格版重做，身份纠偏始终参考 root-base。不能仅凭 SSIM 判定身份通过。未实际检查照片不可写“QA 已通过”。
