# 五套清透人像与光影配方

**所有 EV 为局部曝光初始建议范围，不是模型 API 参数，不保证适用每张照片。** 先检查原图直方图和人物肤色，再微调；背景不应被人物补光一起提灰。

| key | 风格与场景 | 主光/补光 | 色彩逻辑 |
| --- | --- | --- | --- |
| `jp-airy` | 日系清冷空气感：公园、花田 | 阴天/天空柔光，人物局部 +0.15～+0.40 EV | 低反差，低饱和青绿背景；肤色原本暖调，明亮但不泛白 |
| `summer-backlight` | 夏日逆光元气感：海边、草地 | 利用实拍逆光 + 天空/地面反光回填，人物 +0.20～+0.55 EV | 暖高光与微凉暗部；保留发丝光，不虚构太阳 |
| `indoor-cream` | 室内窗边奶油感 | 45°大窗软光、极弱回填，人物 +0.10～+0.35 EV | 米白中性色、柔润高光、轻阴影；不把混合光一律调成橙色 |
| `night-direct-flash` | 夜间直闪/CCD 杂志感 | 前方直闪、背景自然衰减；人物建议 0～+0.30 EV | 清晰硬阴影，暖肤色与冷环境轻分离；检查玻璃反光 |
| `environment-portrait` | 人物风景融合：山海/建筑 | 尊重场景自然主光，人物局部 +0.10～+0.50 EV | 场景保留空间层次，统一肤色/环境色/焦平面 |

## 实际操作优先级

1. 白平衡 → 全局曝光 → 人物蒙版局部提亮 → 阴影结构 → 色彩关系 → 皮肤质感 → 目标画幅/导出锐化。
2. “奶油柔雾”仅允许高亮边缘的微弱光学扩散，**不能模糊眼睛、睫毛、嘴唇和衣服结构**。
3. 暗部仍需黑点锚，轻柔反差不是一片灰；风景背景有自然纹理而非全糊成光斑。
4. `85mm f/1.4` 是拍摄光学条件；已拍摄广角照片不能靠普通调色无损变成 85mm 透视。
5. 用户不允许生成式编辑时，完全不改变实际环境或虚构闪光灯；只用真实像素光影调整。
