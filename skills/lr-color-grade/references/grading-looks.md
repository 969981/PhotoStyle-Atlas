# Color grading look recipes

Recipes are **starting points** for Color Grading wheels + mild WB. Always pull
back if the image looks filtered or skin breaks. Numeric wheel positions differ
by UI — describe intent and use small chroma amounts.

## How to apply any recipe

1. Correct or set intentional WB first.
2. Set global vibrance reasonably.
3. Open Color Grading.
4. Adjust **Shadows** hue/chroma lightly → **Highlights** → **Midtones** last if needed.
5. Tweak Blending / Balance if available.
6. Before/after; reduce chroma 30–50% if overdone.

## Natural documentary

- Goal: invisible grade
- Shadows: none or tiny cool
- Highlights: none or tiny warm
- Midtones: none
- Prefer mixer only for problem hues

## Warm golden hour

- WB: slightly warmer than neutral
- Highlights: warm (amber/gold), low chroma
- Shadows: neutral or slight cool complementary
- Vibrance: mild lift
- Watch skin: if too orange, reduce highlight chroma and orange sat

## Cool cinematic (subtle teal-orange)

- Shadows: teal/cyan, low–moderate chroma
- Highlights: warm orange, lower chroma than social media extremes
- Midtones: slight warm if skin needs life, else neutral
- Balance: bias slightly toward shadows if teal dominates too much
- Do **not** teal the skin; protect oranges in faces via mixer if needed

## Moody low-key

- Coordinate with lighting skill (darker exposure, deeper blacks)
- Shadows: deep blue or teal, low chroma
- Highlights: restrained warm or neutral
- Saturation: often slightly reduced globally

## Faded film / pastel

- Lighting skill: slightly lifted blacks, lower contrast
- Shadows: soft hue (teal or purple), very low chroma
- Highlights: soft warm or pink, very low chroma
- Vibrance: down or neutral; avoid modern HDR punch

## Vibrant travel

- Vibrance up moderately
- Blues (sky/water): slight sat/luma via mixer
- Greens: control neon
- Grading: optional warm highlights only; keep wheels lighter than cinematic teal-orange

## High-contrast B&W (only if requested)

- Convert to B&W
- Use B&W channel mixer for sky/skin separation
- Optional split tone very mild; or skip color wheels

## Product / brand safe

- Neutral accurate WB
- Minimal wheels
- Mixer only to match known brand color if user provides reference
- Never shift logo colors “for the look” without approval

## Failure signs — undo chroma

- Orange plastic skin
- Cyan mud in shadows of hair
- Purple blacks
- Rainbow transitions in sky gradients
- Every photo looks like the same Instagram preset
