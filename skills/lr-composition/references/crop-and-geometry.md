# Crop and geometry controls

## Crop tool basics

Typical controls in Lightroom cloud desktop Crop:

- **Aspect ratio** presets (Original, Free, 1:1, 4:5, 16:9, …)
- **Angle** slider or straighten tool
- **Constrain crop** / lock aspect while resizing
- Drag handles on crop rectangle
- Drag inside rectangle to recompose
- Auto straighten when offered

### Procedure

1. Enter Crop.
2. Set aspect if required by brief.
3. Straighten.
4. Scale/reposition crop rectangle.
5. Confirm (Done / Enter / click outside — match UI).
6. Fit-to-screen review.

### Small-step guidance

- Angle: start with ±0.5–2° corrections; large angles need more aggressive crop.
- If straighten eats too much of the subject, prioritize subject over perfect level and note the tradeoff.
- For architecture, prefer geometry upright before heavy manual angle.

## Geometry / Upright / Transform

Use when crop alone cannot fix perspective.

Typical modes (names vary):

- **Auto / Upright** — general correction
- **Level** — horizon-focused
- **Vertical** — building verticals
- **Full** — stronger multi-axis (use sparingly)
- Manual sliders: vertical, horizontal, rotate, aspect, scale, x/y offset

### Safe order

1. Apply mild upright/level.
2. Inspect faces and circles (wheels, plates) for stretch.
3. Adjust scale/offset if gray empty edges appear.
4. Return to Crop to clean outer frame.

### Avoid

- Stacking Full upright + extreme manual warps
- Correcting creative intentional Dutch angles unless user wants them “fixed”

## Edge cases

| Situation | Approach |
| --- | --- |
| User said no crop | Straighten only if possible with minimal crop; else leave and explain |
| Panorama / stitched | Prefer minimal geometry; easy to break seams |
| Product on pure background | Center or rule-of-thirds per brand; keep full product |
| Group photo | Do not crop people off edges; widen (less crop) |
| Heavy vignette after crop | Revisit Effects later in session; do not “fix” with more crop alone |
